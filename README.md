Note that the RsSt-ShenzhenUV dataset will no longer be updated in this repository after July 20, 2025. 

It is recommended to use our newly updated dataset (namely, the ChinaUIS dataset) released for UV classification. Our ChinaUIS dataset contains a total of 643 UIS samples and 1190 non-UIS samples. All samples come from China's eight megacities with a permanent urban population of more than 10 million (Beijing, Shanghai, Guangzhou, Shenzhen, Tianjin, Chengdu, Wuhan, and Chongqing). 

ChinaUIS Dataset link: https://doi.org/10.57760/sciencedb.19802
Code link: https://github.com/RunyuFan/KANFusion
